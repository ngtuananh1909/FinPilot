# Drop your actual Stitch export here

After Google Stitch generates the screens, export/download its design/code and place under a versioned directory such as:

`design/stitch/exports/v1/` (screens, images, HTML/React prototypes, `DESIGN.md` if available).

The exported assets are **not** bundled in this package and are **not** a running product. Ask Kiro to inspect files and report a screen-to-route mapping before coding. Back up existing source files before integrating; no blind overwrites.
